## 隔板射击战  
是一个好玩的枪战游戏准确来说隔板射击战应该是学校大战.sb3的python版，拥有多种模式，支持双人模式和单人模式，内有多种武器。  


https://github.com/user-attachments/assets/3ad5d924-16e3-4875-983b-f00f8358b6c7


### 手枪  
开局默认枪支，不支持长按发射，按一次发射键发射一次，一发子弹消减1滴血  
### 步枪
击败敌人4次即可获得，射速更快  
### 冲锋枪  
击败敌人8次即可获得。支持长按连射，射速更快。  
### 机枪  
击败敌人12次可获得，射速更快，扫射型，可以over掉空中的敌人。  
### 加特林  
极其强力，射速顶级，适合解决扎堆的敌人。  
### 火箭弹  
一击必杀的武器，攻击范围广，但是射程不够。  
感兴趣的可以看介绍ppt  
ppt下载链接：https://github.com/xuchenruisz/--xcrsz/releases/tag/4  
## seabattle  
这是一个海战游戏，现在版本号为v1.0.0,有两人对抗模式、合作对抗模式和生化模式。  
### 键位  
#### 蓝方键位  
上下左右分别为wsad  
g发射普通攻击，消耗一个技能点造成一点伤害。按y冲撞，消耗3个技能点造成3点伤害，撞到墙上造成1点伤害。按t释放一个3滴血的掩体，消耗2个技能点。  
#### 红方键位  
通过上下左右键控制船只，按0消耗一个技能点发射普通攻击造成1点伤害。按数字1消耗5个技能点发射可穿墙鱼雷造成5点伤害，造成击退。按2消耗3个技能点释放散弹，发射6枚小子弹攻击，每颗0.5伤害。  
### 血量  
双方20滴血。
